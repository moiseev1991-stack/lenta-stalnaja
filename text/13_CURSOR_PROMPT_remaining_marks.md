## Инструкция для Cursor

### Шаг 1: Проанализируй эталонные файлы

Прочитай внимательно 5 готовых файлов с марками: 08_mark_12kh18n10t.md, 09_mark_65g.md, 10_mark_kh20n80.md, 11_mark_20kh13.md, 12_mark_36nkhtyu.md. Запомни структуру:

- SEO_TITLE (до 70 символов с коммерческим хвостом)
- SEO_DESCRIPTION (140–160 символов)
- H1 (3-5 слов, ключевой запрос + "купить")
- INTRO_TEXT (400–600 знаков, вверху страницы над каталогом)
- KEY_SPECS (таблица ключевых характеристик)
- MAIN_TEXT (основной текст под каталогом, 4500–6500 знаков с разметкой H2/H3, таблицами, списками)
- FAQ (7–9 вопросов-ответов)

```bash

```

Скрипт выполнится примерно за 10-15 минут (15 марок × 30-50 секунд на генерацию + пауза). Проверь каждый сгенерированный файл глазами — если где-то Claude напутал с химсоставом или свойствами, поправь руками по справочнику (Марочник сталей и сплавов, ГОСТ 5632-2014).

### Шаг 4: Импортируй все 27 MD-файлов в БД

После генерации в папке `texts_lenta_stalnaja/` будет 28 файлов (1 README + 12 написанных вручную + 15 сгенерированных). Напиши импорт-скрипт, который:

1. Парсит каждый MD-файл по секциям (по заголовкам `## SEO_TITLE`, `## SEO_DESCRIPTION` и т.д.)
2. Определяет целевую таблицу/строку по URL в шапке файла
3. Записывает секции в соответствующие поля БД:
   - SEO_TITLE → `seo_title`
   - SEO_DESCRIPTION → `seo_description`
   - H1 → `h1`
   - INTRO_TEXT → `intro_text` (сохранить как HTML после конвертации MD→HTML)
   - KEY_SPECS + MAIN_TEXT → `main_text` (конвертировать MD в HTML)
   - FAQ → `faq_json` (массив `{question, answer}`)

Используй библиотеку `marked` или `markdown-it` для конвертации MD в HTML.

### Шаг 5: Обнови шаблоны Nunjucks

В `templates/mark.njk` добавь вывод новых полей:

```html
<h1>{{ h1 }}</h1>

{% if intro_text %}
  <div class="page-intro">{{ intro_text | safe }}</div>
{% endif %}

{# тут идёт каталог товаров (существующий код) #}

{% if main_text %}
  <div class="page-content">{{ main_text | safe }}</div>
{% endif %}

{% if faq_json and faq_json.length > 0 %}
  <section class="faq">
    <h2>Частые вопросы</h2>
    {% for item in faq_json %}
      <details>
        <summary>{{ item.question }}</summary>
        <p>{{ item.answer }}</p>
      </details>
    {% endfor %}
  </section>

  {# Schema.org FAQ разметка #}
  <script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "FAQPage",
    "mainEntity": [
      {% for item in faq_json %}
      {
        "@type": "Question",
        "name": {{ item.question | dump | safe }},
        "acceptedAnswer": {
          "@type": "Answer",
          "text": {{ item.answer | dump | safe }}
        }
      }{% if not loop.last %},{% endif %}
      {% endfor %}
    ]
  }
  </script>
{% endif %}
```

Аналогично обнови `templates/category.njk` и `templates/index.njk`.

### Шаг 6: После деплоя

1. Проверь несколько страниц глазами (главная, 1-2 категории, 2-3 марки) — нет ли артефактов вёрстки, правильно ли отображаются таблицы.
2. Проверь HTML-валидность через validator.w3.org.
3. Проверь Schema.org JSON-LD через validator.schema.org — особенно FAQPage разметку.
4. Отправь обновлённый sitemap.xml в Яндекс.Вебмастер и Google Search Console.
5. В Яндекс.Вебмастере → Индексирование → Переобход страниц: вручную отправь URL обновлённых страниц (лимит 20 URL в сутки, начни с самых важных — главная, топ-5 марок, 2 категории).
