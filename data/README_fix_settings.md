# fix_settings_encoding.sql

Файл **не заменяет** всю базу — в админке выполняются только 4 запроса к таблице `settings`.

**Как использовать**
1. Админка → «Восстановление базы данных».
2. Выберите файл `fix_settings_encoding.sql` (из папки `data/`).
3. Нажмите «Загрузить и заменить базу» (подтвердите).
4. Должно появиться: «Успешно выполнено 4 запросов.»

В таблице `settings` будут перезаписаны ключи: `site_name`, `home_title`, `home_h1`, `home_meta_description` — корректным русским текстом в UTF-8. Остальные таблицы не изменяются.

После загрузки обновите главную страницу сайта (при необходимости — с очисткой кэша браузера).
