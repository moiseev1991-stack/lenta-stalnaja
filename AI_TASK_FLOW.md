# Правила работы Cursor с проектом

Краткий поток действий при любой задаче по этому репозиторию.

---

## Обязательно перед задачей

1. **Прочитать `PROJECT_CONTEXT.md`** (в корне проекта) — там контекст, правила, структура сайта и ограничения. Без этого не начинать правки.

---

## Ограничения

2. **Не менять контент товаров** (названия, описания, характеристики в БД и в админке) без явного запроса пользователя.
3. **Не менять утверждённые UI-правила** и блоки из `PROJECT_CONTEXT.md` (USP, фильтры, навигация, lead-section) без запроса.
4. **При конфликте с правилами** — остановиться, сообщить пользователю о конфликте, не вносить изменения без согласования.

---

## После выполнения задачи

5. **Обновить `PROJECT_CONTEXT.md`:**
   - добавить запись в раздел **«История изменений»** по шаблону (дата, задача, что изменено, файлы, что проверить);
   - при необходимости обновить **«Следующие шаги / TODO»**.

---

## Резюме

| Когда | Действие |
|-------|----------|
| Перед задачей | Читать `PROJECT_CONTEXT.md` |
| В процессе | Не менять товары и утверждённые правила без запроса |
| Конфликт с правилами | Остановиться, указать конфликт |
| После задачи | Обновить историю изменений и TODO в `PROJECT_CONTEXT.md` |
