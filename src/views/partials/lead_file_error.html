Файл слишком большой: допустимо до 5 МБ на файл. Заявка не отправлена.

{% elif leadStatus == 'toomany' %}

Можно прикрепить не больше 3 файлов. Заявка не отправлена.

{% elif leadStatus == 'badtype' %}

Такой тип файла не принимается. Подойдут PDF, Word, Excel, PowerPoint, CSV, TXT, изображения, DWG/DXF, ZIP/RAR/7z. Заявка не отправлена.

{% elif leadStatus == 'filesError' %}

Не удалось загрузить файл. Отправьте заявку без файла или попробуйте позже.

{% elif leadStatus == 'badphone' %}

Проверьте номер телефона: нужно от 10 до 15 цифр, например +7 495 123-45-67.

{% elif leadStatus == 'badname' %}

Проверьте имя: от 2 символов, без ссылок и специальных знаков.

{% elif leadStatus == 'spam' %}

Сообщение не отправлено: уберите лишние ссылки и HTML-теги (допустима одна ссылка) и отправьте снова.

{% elif leadStatus == 'refresh' %}

Страница устарела. Обновите её и отправьте заявку ещё раз.

{% elif leadStatus == 'ratelimit' %}

Слишком много заявок за короткое время. Позвоните нам или повторите позже.

{% elif leadStatus == 'captcha' %}

Не удалось пройти проверку от спама. Обновите страницу и попробуйте снова или позвоните нам.
