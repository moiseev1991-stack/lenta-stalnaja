# Контекст проекта (Project Memory)

**Инструкция для Cursor:** перед выполнением любой задачи по этому проекту обязательно прочитай этот файл. Краткий поток работы — см. **AI_TASK_FLOW.md**. Здесь зафиксированы принятые решения, правила и структура сайта. Не меняй утверждённые правила без отдельного запроса пользователя.

---

## 1. О проекте

- **Что это:** Сайт-каталог металлической ленты (лента стальная, нержавеющая и т.д.).
- **Цель:** Показать ассортимент, дать быстрый доступ по маркам стали и по назначению, принять заявки (оставить заявку / заказать).
- **Аудитория:** B2B (производственные компании, юридические лица), подбор по ГОСТ и сортаменту.

---

## 2. Текущий стек / технологии

- **Backend:** Node.js (Express), Nunjucks (шаблоны).
- **БД:** MySQL 8 (`metal_catalog`) — товары/марки/группы; SQLite (better-sqlite3) — категории/лиды/admin.
- **Фронт:** HTML, CSS (один файл `public/css/styles.css`), минимум JS (меню, фильтры в сайдбаре, поиск марок в навигации).
- **Структура:** `src/` — сервер, роуты, контроллеры, сервисы, шаблоны; `public/` — статика; `data/` — SQLite БД (если есть).
- **Картинки товаров:** `/uploads/products/{image_filename}` → `public/uploads/products/`; если файл отсутствует — placeholder.

---

## 3. Актуальная структура сайта

- **Главная** (`/`) — герой, подбор (марки / по назначению), блок преимуществ (USP), документы/работаем с (lead-section), CTA.
- **Каталог:**
  - Пункт «Каталог» в меню убран; доступ через «Марки стали» и «По назначению».
  - **Главная / лента** — `/` (герой, фильтры, товары, пагинация).
  - **Марка стали** — `/:gradeSlug/` (страница марки с фильтрами и списком товаров).
  - **По назначению** — `/group/:slug/` (группа назначения, марки в группе, фильтры, товары).
- **Карточка товара** — `/:gradeSlug/:productSlug/` (фото, характеристики, кнопки «Заказать» / «Задать вопрос», похожие товары, в конце — блок `lead-section`).
- **Статические страницы:** О компании (`/about/`), Доставка (`/delivery/`), Оплата (`/payment/`), Контакты (`/contacts/`), Карта сайта (`/sitemap/`), 404.
- **Единый блок в конце контента:** На страницах товаров и категорий (в т.ч. лента, марка, группа) в конце выводится блок `lead-section` (документы, «Работаем с», кнопка «Оставить заявку»). Партиал: `partials/lead_section.html`.

---

## 4. UI/UX правила

- **Стиль:** Современный, компактный, без лишних пустот.
- **Блоки преимуществ:** Компактные карточки (USP), не как кнопки: без рамки, без обводки при наведении; визуально — «таблетки» с лёгкой тенью (см. `.header-strip-usp .usp-card`).
- **На главной и внутренних** — использовать только компактные блоки преимуществ, без дублирования больших блоков.
- **Навигация:** В шапке — Главная, выпадающие «Марки стали» и «По назначению», О компании, Доставка, Контакты. Под шапкой — полоска с чипсами (марки / по назначению) и 4 карточки USP. Блоки «Марки стали» и «По назначению» компактные: по умолчанию одна строка чипсов, при переполнении — кнопка «Показать все» / «Свернуть» справа от заголовка, раскрытие независимое для каждого блока.
- **Мобильная версия:** Удобный UX (бургер-меню, выдвижной фильтр каталога, адаптивная сетка).

---

## 5. Правила по каталогу и карточкам товаров

- **Названия товаров в карточках:** Обрезать аккуратно (line-clamp или аналог), без «хвостов» и лишних цифр в конце; показывать марку, размер, состояние — читаемо и коротко.
- **Карточка товара:** Фото, краткое описание (если есть), таблица характеристик (марка, толщина, ширина, длина, поверхность, состояние, ГОСТ, артикул, цена, наличие), кнопки «Заказать» (ведёт на `/contacts/#lead`) и «Задать вопрос», блок «Похожие товары», затем `lead-section`.
- **На странице товара** нет блока «Документы + форма заказа» (product-docs-cta-inner и lead-form-compact убраны); заявка — через Контакты.

---

## 6. Правила по фильтрам

- **Толщина:** Поддержка диапазона 0.01–2.5 мм; в фильтре — чекбоксы по значениям из данных (`filterValues.thickness`).
- **Ширина:** Значения из данных (`filterValues.width`).
- **Поверхность:** Из данных (`filterValues.surface`).
- **Состояние:** Фиксированный набор — только следующие варианты (не добавлять без согласования):
  - Мягкая (value: `soft`)
  - Нагартованная (`hard`)
  - Полунагартованная (`semi`)
  - Высоконагартованная (`extra`)
- **ГОСТ:** Значения из данных (`filterValues.standard`), чекбоксы.
- **Поиск:** Поле поиска по марке/размеру в сайдбаре фильтров.
- Фильтры передаются через GET; при выборе марки/группы в шапке — предзаполнение фильтра по марке.
